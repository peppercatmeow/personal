Three interactive demos of production ML systems patterns — retrieval-augmented generation, autoscaled LLM inference, and LoRA fine-tuning. Each runs 100% in your browser: real algorithms on toy data, no backend.

Demo 01

RAG service with an eval harness

Hybrid BM25 + dense retrieval over a doc corpus, adjustable chunking, and an eval harness that scores precision/recall/MRR so you can A/B configs. Tune the knobs and watch the metrics move.

What it demonstrates

  • Hybrid retrieval (BM25 + TF-IDF) with tunable blend
  • Chunking strategy comparison
  • Eval harness with baseline snapshots and before/after deltas

Demo 02

Autoscaled LLM inference endpoint

A discrete-event simulator of an LLM serving fleet with continuous batching, KV-cache math, and a latency-driven autoscaler. Drive a load spike through it and see the fleet react.

What it demonstrates

  • Continuous batching visualization with live queue dynamics
  • KV-cache memory calculator (real formula)
  • Autoscaling on p95 latency with cost-per-token readout

Demo 03

LoRA fine-tune: before/after benchmarks

Trainable-parameter math for adapter fine-tuning, benchmark comparison of base vs LoRA vs RAG, and a "which lever do I pull" decision guide. See exactly what each adaptation strategy costs and buys you.

What it demonstrates

  • Exact LoRA parameter accounting across ranks and target modules
  • Full-finetune vs LoRA vs QLoRA memory comparison
  • Base vs LoRA vs RAG benchmark charts
